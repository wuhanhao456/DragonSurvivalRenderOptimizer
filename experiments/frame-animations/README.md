# 同帧动画复用实验（不编译、不进入客户端 jar）

原型在 `tickAnimation` 后、`setCustomAnimations` 前捕获本地骨骼姿态，保留 Molang 查询、世界矩阵与后续自定义动画；只接受已审查的 Core 控制器，表情、触发动画、回调及修改过的动画资源保留原路径。

2026-10-07 的隔离整包检查中，Complementary Unbound r5.9 原版设置的 `shadowEntities = false`。4 末与 4 地黄龙各采样 5 秒，没有同帧复用命中（分别 4560 与 5612 次未命中）。这是功能探索，不能证明收益。按照“收益不明确的改动不进入最终版本”的规则，移出编译源集，移除配置与生产 Mixin，保持原动画计算。

这些文件是保留的实验记录，依赖原型阶段的配置和预算接线，不能直接复制到发布工程。重新接入前必须在启用实体阴影/重复渲染的场景验证输入、控制器事件、自定义动画及实际帧时间，并补全回调/失效测试。`LocalBonePoseTest` 在原型阶段运行通过，只证明局部姿态与标记存储独立，不能证明动画缓存完整正确。
