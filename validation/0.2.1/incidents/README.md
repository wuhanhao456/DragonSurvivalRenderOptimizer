# 0.2.1 修正记录

这些运行不计入最终有效帧率比较。失败的整次运行仍保留原失败状态，功能覆盖只选取已经通过的前缀，再补充针对失败的复核。

- driver-repair.json：测试时钟重置导致无法前进；修正驱动。
- runtime-first、runtime-targeted：初始移动和攻击输入不足，修正为真实 walk/bite 控制器后通过；吐息定位失败继续留存。
- locator-baseline：关闭低端支持后的定位基线也为空；原共享骨骼可见状态受到之前姿态缓存影响。
- reload-crash：只读渲染层列表破坏资源重载的注册，改为仅过滤执行阶段。临时定位绕行方案随后撤回。
- preview-visibility：截图审查发现物品栏头部隐藏，停止候选性能测量；原始完整 CSV 留存。姿态恢复现保留 DS 当前渲染阶段控制的临时 Neck 可见性。
- far-camera：最终候选吐息／恢复通过后远处断言失败；固定镜头的定向复核中两个 NPC 姿态各唯一。原异常没有改为通过。
- performance-first.json：光影单玩家初测 1% Low 为 -10.46%，触发一次该配对的定向复核；原六组主轮及 CSV 均保留。
- scene-sync：性能驱动在种族同步完成前读取状态，修正等待顺序后才开始有效配对测量。

各有效阶段的原实例、原始 JSON 和 jar 哈希见 ../runtime/result.json。变更类与最终候选的复核范围见 ../final-guard-verification.json。早期动作前缀来自之前候选；最终 jar 单独复核吐息、恢复、远处、物品栏头部、CPU 回退、开关恢复、重载与清理。
