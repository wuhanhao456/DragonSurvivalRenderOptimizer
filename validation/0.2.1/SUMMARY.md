# DSRO 0.2.1 验证

最终客户端 SHA-256：26b839419377d79eed060d803c3bd737f6d75fd871cfe88ec999e46f05eddab3。

0.2.1 为正式版本，新增默认关闭的“低端显卡支持”。保留当前模型，省去龙魂模型、动态皮肤合成和外观层，近处动画约 5 Hz、远处持有姿态。只调整客户端渲染，不修改服务器状态、皮肤 NBT 或存档。

## 方法与硬件

本机 AMD EPYC 7F52 / NVIDIA RTX 5060 Ti，NVIDIA 610.88，Microsoft Java 21.0.11，Windows Server 2025。使用冻结的 225 模组整包：DS 2.0.71、GeckoLib 4.9.3、Core 0.10.1、Iris 1.8.14-beta.1、Sodium 0.8.13。输入文件、版本与 SHA-256 见 [fixture-provenance.json](fixture-provenance.json)。不复制用户存档或启动器身份。

同一最终 jar，低端支持主轮 off/on 各一次；另仅复核一组失败配对，每景预热 15 秒、采样 60 秒，三种场景 × 无光影／Complementary Unbound r5.9。1280×720、视距 6、8 GiB 堆、VSync 关闭、窗口有效限帧 260（无限帧选项）、WGL swap interval 0、同一固定镜头。12 玩家保留三种实际模型；开关两侧的模型、body、种族、位置与规模相同。使用合成客户端玩家，未测真实多人网络负载。固定镜头距多数远程玩家及 NPC 超过 32 格，远处姿态持有是收益的一部分；近处动作由功能检查单独覆盖。

FPS 取完整显示循环帧间隔；Low 为最慢 ceil(N×比例) 帧时间的均值取倒数。平均 FPS 与 1% Low 均不得退步超过 5%。这是一次短测，不是历史 3×300 秒正式 Low 矩阵，也没有使用低端实体硬件，不保证所有设备得到相同提升。

## 功能与修正

[19 项功能覆盖](runtime/scenes.json) 包括三种模型的待机、行走、飞行和攻击，两种 NPC 的对应动作、吐息施放与恢复、近远处、物品栏、强制 CPU 路径、关闭恢复及资源重载。行走与攻击检查要求实际控制器包含 walk／bite；近处姿态持续变化，动画求值约每四 tick 一次，远处 NPC 姿态唯一。皮肤 NBT 保持不变。最终 jar 的 [五项定向复核结果](runtime/targeted-result.json) 通过，受管纹理、网格与姿态清理后均为零；[恢复后的配置](runtime/restored-client.toml) 保留原预算值并关闭低端支持。

功能覆盖由有效前缀与失败后的定向复核合并，见 [result.json](runtime/result.json)。没有把失败的整次运行标为通过：计时驱动重置、行走／攻击输入不足、定位为空和重载崩溃均在 [incidents](incidents) 留存。截图复核发现缓存恢复覆盖了 DS 第一人称临时 Neck 隐藏状态，使物品栏头部与吐息定位受到影响。已改为保留当前渲染阶段负责的 Neck 可见性，并撤掉临时定位绕行方案；相关候选的帧率记录作废，原始数据留存，最终修正的吐息／恢复与五项预览／生命周期定向复核通过；远处复核使用完整显示 NPC 的固定镜头，两个 NPC 的姿态各唯一。原远处断言异常保留，未据此断言全部相机组合都已验证。

重载崩溃由本次只读层列表造成，已改为仅过滤渲染层执行；原 getRenderLayers 的可变注册接口保留。最终候选定向重载通过。候选变化与各功能阶段的 jar 哈希见 [final-guard-verification.json](final-guard-verification.json)。

25 项初始 Java 单元测试及真实 OpenGL 检查各运行一次通过；颈部可见性修正新增的一项单独回归检查通过，共 26 项，见 [unit-tests.json](unit-tests.json)、[gl-results.json](gl-results.json)。GPU 输出校验含标准／Iris 54 字节布局、三个独立姿态、纹理复制／延迟读取、异常 GL 状态恢复，GL error=0。发布 jar 不含验证驱动或第三方依赖。
